# ecagent
Agentic AI assistant for discovering and planning extracurricular activities

## Repo Structure

```
ecagent/
├── agent/                          # Agent implementation (see docs/agent.md)
│   ├── agent.py                    # Main agent: router (supervisor loop), calls subagents, checks replies
│   ├── memory.py                   # Structured notes (state, summary, plan), context management, save/restore
│   ├── compactor.py                # Resolve contradictions in memory, summarize near the token limit
│   ├── retriever.py                # Find + score events/clubs (DB keyword search, web fallback)
│   ├── recommender.py              # Rank activities (soft preferences) and candidate plans (pairwise judge)
│   ├── scheduler.py                # Generate + check candidate plans, calendar tools (SimulatedCalendar)
│   └── model_log.json              # Action log, one JSON object per line (generated)
│
├── docs/                           # Project documentation
│   ├── agent.md                    # Agent design, experimental setup, references
│   ├── design-decisions.md         # Design decisions (benchmark, eval, agent components)
│   ├── benchmark.md                # Simulated student profiles: schema + maintenance
│   └── evaluation.md
│
├── eval/                           # Benchmark and evaluation
│   ├── eval.py                     # Evaluation pipeline (full_agent vs. no_compact vs. single_pass)
│   ├── manual_grading.py           # Manual quality scores (1-5) for the last batch of full_agent trials
│   ├── benchmark-tasks.json        # Benchmark task ids + queries
│   ├── simulated-profiles.json     # Simulated student profiles
│   ├── generate_profiles.py        # Source of truth for profile data, writes the JSON
│   ├── validate_profiles.py        # Schema + ground-truth consistency checks
│   └── results.json                # Results, one batch per eval run
│
├── scraper/                        # Campus event + RSO scraping
│   ├── scrape.py                   # Weekly scraper (run: python -m scraper.scrape)
│   ├── db.py                       # SQLite schema + event/club search queries
│   └── tools.py                    # Agent tool definitions (database search, web search + fetch)
│
├── data/
│   ├── campus.db                   # Scraped events + clubs (generated by scraper)
│   └── snapshot-2026-10-27.db      # Frozen snapshot for eval (week of 2026-11-02)
│
├── unit_tests/                     # Unit and integration tests
│   └── test-eval.py
│
├── utils.py                        # Shared base class: Claude API calls (requests), token counting, logging
├── LICENSE
├── README.md
└── requirements.txt
```

## Setup

```bash
pip install -r requirements.txt
export ANTHROPIC_API_KEY=...        # all modules use claude-sonnet-4-6 (MODEL in utils.py)
python -m scraper.scrape            # build data/campus.db (or copy the eval snapshot into data/)
```

Run everything from the repo root (imports are `agent.*`, `scraper.*`, `utils`).

## Usage

```python
from agent.agent import ECAgent

agent = ECAgent(memory_path="memory.json")          # memory saved after each turn
reply, selection = agent.run("Can you find me an activity that works with my schedule?")
```

`run` returns the reply and the activities shown or added this turn. Plans are only added to the calendar after the student approves them in the next message.
